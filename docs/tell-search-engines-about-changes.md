---
title: Tell search engines when a page changes
tags: indexnow, bing, yandex, search engines, indexing, crawl, seo
---

**IndexNow** tells Bing, Yandex, Naver and Seznam the moment a page is created, edited or deleted, instead of waiting for them to find it. Google does not use IndexNow. Pages set to noindex are not sent.

## Switch it on

Open **IndexNow** and turn it on. Only the live site sends pages.

## Send everything

**Send all pages** sends every page once, for example when you first switch it on. After that the button reads **Send all pages again**, and it is limited so it can only be used every so often. The page says how long you have to wait.
